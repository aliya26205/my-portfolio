# 🌸 Aliya Banu - Flutter Portfolio

A personal portfolio website and mobile application built using **Flutter and Dart** as part of a hands-on Mobile Application Development workshop.

The project showcases my profile, technical skills, projects, education, and contact/social links in a responsive portfolio application.

## 🌐 Live Portfolio

🔗 **[View My Portfolio](https://aliya26205.github.io/my-portfolio/)**

## 📱 About the Project

This portfolio was developed to apply the concepts learned during the Mobile Application Development workshop.

The project started with basic Flutter concepts such as displaying text and gradually evolved into a complete portfolio application with navigation, reusable widgets, forms, buttons, a drawer, responsive layouts, and external links.

The application was also built as an Android APK and successfully tested on a physical device.

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/aliya26205/my-portfolio.git
```

### 2. Open the project

```bash
cd my-portfolio
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

**For Chrome:**

```bash
flutter run -d chrome
```

**For Android:**

```bash
flutter run
```

---

## 📦 Build the Application

### Build for Web

```bash
flutter build web --release
```

### Build Android APK

```bash
flutter build apk --release
```

The generated APK can be found at:

```text
build/app/outputs/flutter-apk/app-release.apk
```

---

## 🌐 Deployment

The web version of the portfolio is deployed using **GitHub Pages**.

Every update pushed to the `main` branch can be automatically built and deployed using **GitHub Actions**.
